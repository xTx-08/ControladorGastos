# 💰 Controlador de Gastos en Java

Aplicación de consola desarrollada en Java diseñada para ayudar en la gestión y distribución inteligente de presupuestos personales (quincenales/mensuales) con formato de moneda localizado (`es-CO`).

---

## 🚀 Características Principales

* **Interfaz Interactiva por Consola:** Menú intuitivo que guía al usuario paso a paso.
* **Cálculo y Distribución de Presupuesto:** Asignación automática de porcentajes para ahorro, gastos fijos, ocio y reservas.
* **Formato Monetario Localizado:** Visualización de montos adaptados al estándar de Colombia (`es-CO`).
* **Código Modular:** Aplicación de buenas prácticas de programación en Java y convenciones de nomenclatura (CamelCase y PascalCase).

---

## 🛠️ Tecnologías y Herramientas Utilizadas

* **Lenguaje:** Java (JDK 17 o superior recomendado).
* **Control de Versiones:** Git y GitHub.
* **Entorno de Desarrollo:** Visual Studio Code (VS Code).
